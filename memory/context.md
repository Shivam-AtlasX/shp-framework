# Session Context

## Purpose
Tracks information about the user, project, and session goals to ground SHP reasoning.

## Format

```markdown
## User Profile
- Expertise level: [Inferred]
- Domain focus: [Primary domain]
- Communication preference: [Depth, formality]

## Project
- Name: [If provided]
- Description: [What is being built]
- Stage: [Prototype / Production / Review]

## Session Goals
- [Goal 1]

## Constraints
- [Constraint 1]
```
